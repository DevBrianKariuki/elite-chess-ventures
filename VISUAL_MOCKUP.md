## 🎬 Animation Sequence

```
PAGE LOAD SEQUENCE:

1. Hero Section (0s)
   ├─ Badge fades in
   ├─ Headline slides up
   ├─ Body text fades in
   ├─ Buttons appear
   └─ Stats animate in (staggered)

2. Scroll Animations
   ├─ Section appears when 20% visible
   ├─ Cards stagger in (0.1s delay each)
   ├─ Images fade + slight zoom
   └─ Stats count up when visible

3. Hover Animations
   ├─ Cards: Lift 4px + shadow increase
   ├─ Buttons: Darken + lift 2px
   ├─ Links: Color change
   └─ Images: Scale 105%

4. Click Animations
   ├─ Buttons: Press down effect
   ├─ FAQ: Smooth expand (300ms)
   └─ Mobile menu: Slide in (400ms)
```

## 🎨 Visual Design Principles

### Hierarchy
```
1. Hero headline (biggest, boldest)
2. Section titles (large, serif)
3. Card titles (medium, sans-serif)
4. Body text (readable, comfortable)
5. Captions (smallest, subtle)
```

### Contrast
```
High Contrast:
- Headings on white background
- White text on dark footer
- Red CTAs against neutral backgrounds

Low Contrast:
- Body text (slight gray, not pure black)
- Borders (light gray)
- Disabled states
```

### Alignment
```
Left-aligned:
- Most text content
- Form labels
- List items

Center-aligned:
- Section headlines
- Stats
- Testimonials

Right-aligned:
- Navigation CTAs (desktop)
```

### Repetition
```
Consistent patterns:
- Card layouts
- Button styles
- Icon usage
- Spacing rhythm
- Border radius
```
